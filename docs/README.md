# Documentation

- `architecture/` describes how the pipeline is built and why.
- `decisions/` holds decision records and the open questions that block
  implementation.
- `process/` holds working practice.
- `spec/` holds authoritative specifications.

## Rule

A claim in this directory is either measured on this tree or marked as
unmeasured in the same sentence that makes it. Counts, benchmark results,
and corpus statistics are measured or they are absent. This rule exists
because the project's subject matter is the suppression of confident
unsupported assertion, and documentation that violates it undermines the
artifact it describes.
