[ac1.tally.x_sequence.d00]
This book shows how to count marks using first, next, last, and tally to know how many.

[ac1.tally.x_sequence.s01]
Begin with one mark, then follow with another, and keep going until the end, counting each one to know how many. The tally keeps count, showing how many, not just a few, but every one. No mark is left out, not even the smallest, the one that came after the last.

[ac1.tally.x_sequence.s02]
first mark made, next mark made, last mark made, end came, tally kept.

[ac1.tally.x_sequence.s03]
score counted, each mark shown, one by one, no more, no less, no doubt.

[ac1.tally.x_sequence.s04]
first mark shown, next mark shown, last mark shown, end known, tally true.

[ac1.tally.x_sequence.s05]
ever count, every mark, no wrong, no missing, no doubt, no need to fear. Ever count, every mark, no wrong, no missing, no doubt, no need to fear. Each mark made follows the next, no step skipped, no order lost. First comes one, then two, then three, each number true and known.

[ac1.tally.x_sequence.s06]
begin, next, last, end, ever, first, follow, tally, score, all one story.

[ac1.tally.x_sequence.s07]
Each mark begins a new step, and every mark counts to know how many. Each mark counts to know how many steps have been taken. The next mark comes after the last one, not before. Every mark is a part of the same story, told in order. No mark is alone; each one belongs to the group.

[ac1.tally.x_sequence.s13]
first, next, last, and end—each word helps the tally grow
