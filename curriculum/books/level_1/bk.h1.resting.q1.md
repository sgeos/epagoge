[h1.resting.q1.d00]
You did not check the first thing. So you have not checked the next one either.

[h1.resting.q1.a01]
Did you check the first thing? You did not check the first thing.

[h1.resting.q1.a02]
Did you check the next one? You have not checked the next one either.

[h1.resting.q1.a03]
Why did you not check the first thing? You did not check the first thing because you did not want to.

[h1.resting.q1.a04]
What happens if you do not check the first thing? If you do not check the first thing, you cannot be sure it is safe.

[h1.resting.q1.a05]
What about the next one? The next one is not checked because the first one was not checked.

[h1.resting.q1.a06]
Can you depend on something you did not check? You cannot depend on something you did not check.

[h1.resting.q1.a07]
Can you rest if you are not sure? You cannot rest if you are not sure what is true.

[h1.resting.q1.a08]
What should you do before you rest? You should check the first thing before you rest.

[h1.resting.q1.a09]
How can you be sure? You must check each thing, one by one, to be sure.

[h1.resting.q1.a10]
What is the first step? The first step is to check the thing that comes first.

[h1.resting.q1.a11]
Can you do it again? Yes, you can do it again, but only after checking the first thing.

[h1.resting.q1.a12]
What should you do next? You should check the next one after you check the first one.

[h1.resting.q1.a13]
Did you check the first thing? You did not check the first thing, so you have not checked the next one either.

[h1.resting.q1.a14]
What happens when you do not check the first thing? When you do not check the first thing, you cannot depend on the next one being safe or correct, and the rest will be wrong too.

[h1.resting.q1.a15]
What happens if you do not check the first thing? If you do not check the first thing, you cannot depend on the next one being right.
