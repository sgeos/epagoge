[ac1.tally.q1.d00]
Make one mark for each one. Count the marks to know how many.

[ac1.tally.q1.d01]
A score is a number that shows how many times something happened.

[ac1.tally.q1.d02]
A tally is a mark made to count things, one mark for each thing.

How do you count a group of apples? Make one mark for each apple, and count the marks to know how many.
