[h1.findout.x_mistake.d00]
How do you know? Let us go and find out. Now we have settled it.

[h1.findout.x_mistake.s01]
We go to find what is correct, not a mistake, using looking and discover.

[h1.findout.x_mistake.s02]
We look at the apple, and it is red, not green, so we know it is correct.

[h1.findout.x_mistake.s03]
We check the book, and it says “dog,” not “cat,” so we know it is correct.

[h1.findout.x_mistake.s04]
We see the sky, and it is blue, not black, so we know it is correct.

[h1.findout.x_mistake.s05]
We find the ball, and it is round, not flat, so we know it is correct.

[h1.findout.x_mistake.s06]
We listen to the bell, and it rings, not stops, so we know it is correct.

[h1.findout.x_mistake.s07]
We feel the blanket, and it is soft, not rough, so we know it is correct.

[h1.findout.x_mistake.s08]
We read the note, and it says “yes,” not “no,” so we know it is correct.

[h1.findout.x_mistake.s09]
We see the moon, and it is bright, not dark, so we know it is correct.

[h1.findout.x_mistake.s10]
We look for answers because we want to know what is correct and not make a mistake.

[h1.findout.x_mistake.s11]
We follow the path, but soon we see a wrong turn—this is a mistake.

[h1.findout.x_mistake.s12]
We stop and think: is this right? We must decide if it is correct.

[h1.findout.x_mistake.s13]
We go back and check again, and now we see the truth: this path is wrong.

[h1.findout.x_mistake.s14]
We change direction, and now we know: the mistake was ours.

[h1.findout.x_mistake.s15]
We smile and say: now we have settled it—truth is found.
